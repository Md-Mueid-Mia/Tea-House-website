# 🍵 Tea House Website

A modern, responsive (Single page) website for a premium tea house built with HTML, TailwindCSS, and FontAwesome.

![Tea House Banner](images/banner.png)
[Website live link](https://tea-house-website.netlify.app)

## ✨ Features

- 📱 Fully responsive design for all devices
- 🎨 Modern UI with gradient colors and shadows
- 🫖 Featured tea products showcase
- ⭐ Customer reviews and ratings
- 📰 News and events section
- 📨 Newsletter subscription
- 🔗 Social media integration

## 🛠️ Technologies Used

- HTML5
- TailwindCSS
- Google Fonts (Manrope)
- FontAwesome Icons
- Gradient Designs

## 🎯 Key Sections

1. **Hero Banner**
   - Eye-catching header with trust ratings
   - Call-to-action button

2. **Featured Products**
   - Milk Tea
   - Black Tea
   - Lemon Tea
   - Green Tea

3. **Premium Quality Section**
   - Unique taste presentation
   - Quality guarantees
   - Fresh tea showcase

4. **Client Reviews**
   - Interactive testimonial cards
   - Customer feedback display

5. **News & Updates**
   - Latest events
   - Special offers
   - Reward points system

## 💻 Setup

1. Clone the repository
2. Open index.html in your browser
3. For development, install TailwindCSS dependencies:

npm install -D tailwindcss @tailwindcss/forms
